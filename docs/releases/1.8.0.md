# C4X 1.8.0 release notes

Supported AI SDK, architecture checks and visual editing fixes.

## Highlights

- **Review C4 notation as you write.** Diagnostics flag missing descriptions, technologies and relationship labels, incorrect abstraction levels and disconnected elements. Rules are configurable and do not prevent previewing.
- **Connect architecture to code.** Map components with `$code` globs, export dependency-cruiser rules and bring conformance results back into editor diagnostics.
- **Edit diagrams in Markdown.** Open the visual editor from the preview link, source CodeLens or right-click menu. Preview links now target the correct file and fence even after repeated rendering or a change of editor focus.
- **More reliable visual changes.** Fixes cover relationship save ordering, repeated endpoint changes, multi-selection dragging, accidental move recording and toolbar overlap. Changes remain staged and reviewable before saving.
- **Current Gemini integration.** Text/image generation and model discovery use `@google/genai`. The SDK loads only when AI is used; failover errors preserve the failover request's own cause.
- **Package and activation improvements.** Whitespace compaction reduces activation overhead while keeping source maps and complete dependency licence notices.

## Getting started

Open a `.c4x` file and run **C4X: Open Preview**. For Markdown, open the built-in preview and click **Edit C4 diagram** below a rendered diagram; confirm **Open** if the IDE asks to open the extension link. The source CodeLens and right-click command provide additional entry points. Turn on **Edit C4 Diagram**, select or drag a node, change properties, inspect staged changes, then save or discard.

Requires VS Code 1.90 or a compatible host with Node 20 or later. Save Markdown documents to a local file before using the preview Edit link. Ordinary rendering and editing run locally; Gemini features require an API key.

## Known limitations

Typed C4 boundaries cannot yet be moved or resized. Pan/zoom-only changes are not persisted across reloads. Restored drafts can attach to the wrong statement, relationship labels can move after saving, and long descriptions can overflow. Draft-identity hardening is deferred to 1.8.1 alongside restoration identity fixes. Palette creation and deletion remain planned for 1.8.1. These are limitations, not completed features.

The development/publishing dependency audit has a dated `braces` high-severity exception expiring 2026-11-07; that package is absent from the extension VSIX.

Screen-reader announcement and browser HTML print-pagination verification are deferred to 1.8.1; neither is claimed verified for this release.
