## Positioning in one paragraph

C4 architecture diagrams as version-controlled text in your repository, edited visually by dragging. No Java, Graphviz, Docker or rendering service; preview and export run locally. Gemini generation uses your own API key. The README and this page say the same thing; where they differ, the README and the changelog win.
