## 5. Regenerate

The standard command lists every installed package with its declared licence (pnpm lockfile; includes
dev dependencies unless `--prod` is passed):

```sh
pnpm licenses list --json
```

This file was produced with an external generator, `gen_deps.py`, a stdlib-only Python script kept
outside this repository. It reads manifests and lockfiles, uses installed metadata where present and
otherwise makes read-only requests to public registries (npm, PyPI, GitHub licence API, crates.io):

```sh
python3 -I gen_deps.py --repo . --out DEPENDENCIES.md --overrides overrides.json
```

The curated input it reads (`overrides.json`): licences confirmed by reading the licence file in the
published package, dispositions, and in-tree items found by hand.
